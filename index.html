Dashboard Lending Club

Análisis de limpieza y tratamiento de datos

¿Qué representa este dashboard?

Este dashboard presenta el proceso completo de limpieza y preparación de datos realizado sobre el dataset de préstamos de Lending Club. El objetivo principal fue identificar columnas con valores nulos, aplicar técnicas de imputación y eliminar información que pudiera afectar la calidad del análisis.

Durante el proceso se analizaron más de 2.26 millones de registros y 151 columnas originales. Después del tratamiento de datos, el dataset quedó completamente limpio, sin valores nulos y listo para futuros análisis estadísticos, modelos predictivos o proyectos de ciencia de datos.
